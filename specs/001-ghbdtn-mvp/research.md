# Research: Ghbdtn MVP

Основа — `.planning/RESEARCH.md` (2026-10-14). Здесь — решения, принятые для плана, и проверка спайком.

## R1. Проверка существования слова

- **Decision**: `spellbook` 0.4 (MPL-2.0, Hunspell-совместимый, helix-editor) со словарями Hunspell
  ru_RU (А. Лебедев, BSD-подобная) и en_US (SCOWL, permissive) из `wooorm/dictionaries`.
  Второй слой — частотные списки FrequencyWords 2018 (CC-BY-SA-4.0), топ-50K на язык, и
  пользовательские слова. Слово «есть», если его принимает любой слой.
- **Rationale**: спайк 2026-10-15 — загрузка ru 48 мс, en 8 мс; проверка ~1 мкс; оба словаря —
  25 МБ рабочего набора. Hunspell знает все словоформы (пришёл/пришел, ёлка/елка), частотный список
  добавляет имена и термины, которых нет в Hunspell (claude, npm).
- **Alternatives**: FST из развёрнутых форм (нужен unmunch, сотни МБ исходников); OpenCorpora
  (CC-BY-SA, большой); только частотные списки (нет хвоста редких форм → ложные исправления).

## R2. Буквы слова в обеих раскладках

- **Decision**: статические таблицы скан-код → символ для ЙЦУКЕН (0x0419) и US QWERTY (0x0409),
  с Shift и Caps Lock. Активная раскладка — `GetKeyboardLayout(thread окна)`, младшее слово LANGID.
  Другая раскладка — утилита молчит.
- **Rationale**: чистые функции, тестируются без Win32; `ToUnicodeEx` из чужого потока портит
  состояние dead keys и зависит от состояния клавиатуры. Раскладок только две (FR-016).
- **Alternatives**: `ToUnicodeEx` с двумя HKL — нужно для произвольных раскладок, вне MVP.

## R3. Решение о смене раскладки

- **Decision**: `typed` вне словаря текущего языка И `alt` в словаре другого. Длина < 3 — нет.
  Длина 3–4 — `alt` обязан быть в частотном списке (не только Hunspell). Слова с признаками кода
  (FR-063/065) — нет. Пунктуация на конце, которая в другой раскладке буква, решается перебором:
  сначала слово без хвоста, затем с хвостом как буквой.
- **Rationale**: двойное подтверждение режет ложные срабатывания (конституция III); частотный
  фильтр для коротких — защита от «yt» → «не» при живом английском «yt»-подобном мусоре.
- **Alternatives**: n-граммы для неизвестных слов — отложено, пока корпус не покажет нужду.

## R4. Опечатки

- **Decision**: свой генератор правок расстояния 1 (удаление, вставка, замена, перестановка
  соседних) по алфавиту языка; кандидат принимается, если он «есть» по R1 и в частотном списке.
  Вес: замена на соседнюю клавишу 0,5, перестановка 0,6, удаление/вставка повтора 0,5, прочее 1,0.
  Score = ln(freq) − 4·вес. Исправляем, если лучший кандидат один с весом ≤ 0,6 и отрыв по score
  ≥ ln(20) от второго. Длина ≥ 4.
- **Rationale**: dist 1 = ~600 проверок на слово ≈ 0,6 мс — SymSpell не нужен. Порог «один явный
  кандидат» из решения волны 1.
- **Alternatives**: крейт `symspell` — лишняя зависимость и память ради dist 2, который не нужен.

## R5. Перехват клавиатуры

- **Decision**: `WH_KEYBOARD_LL` в отдельном потоке с `GetMessageW`. Колбэк: отбросить свой ввод
  (`dwExtraInfo == 0x4748_4244` «GHBD»), положить событие в `crossbeam_channel` (bounded, try_send),
  решить «съесть» по атомарным флагам: `ARMED_UNDO` (Ctrl+Backspace), `HOTKEYS` (Pause,
  Shift+Pause), `HOLD` (идёт исправление — съедать всё, складывать в очередь задержанных),
  `PENDING_WORD` (Enter при непустом слове). Panic → `catch_unwind`, при ошибке — пропустить.
- **Rationale**: колбэк без аллокаций и блокировок (конституция II). Решения «съесть» нужны
  синхронно — флаги атомарные, их ставит рабочий поток.
- **Watchdog**: рабочий поток раз в 2 с сравнивает `GetLastInputInfo` с временем последнего
  события хука; расхождение > 2 с при клавиатурном вводе — переустановка хука. Плюс переустановка
  на `WTS_SESSION_UNLOCK` и выход из сна.

## R6. Вывод

- **Decision**: `SendInput` одним пакетом: N×Backspace, текст `KEYEVENTF_UNICODE` (суррогатные пары
  поддержаны), разделитель; все события с маркером в `dwExtraInfo`. Смена раскладки —
  `PostMessageW(hwnd фокуса, WM_INPUTLANGCHANGEREQUEST, 0, HKL)` с `HKL` из `GetKeyboardLayoutList`,
  ожидание применения до 50 мс опросом `GetKeyboardLayout`. Задержанные клавиши (HOLD) —
  переотправка исходными vk/scan после исправления.
- **Enter**: съеден хуком при непустом слове → исправление → `SendInput` Enter с маркером.
- **Rationale**: Unicode-ввод не зависит от гонки раскладки; скан-коды — для задержанных клавиш,
  чтобы они легли в новую раскладку и сочетания работали.

## R7. Контекст окна

- **Decision**: поток контекста с `SetWinEventHook(EVENT_SYSTEM_FOREGROUND | EVENT_OBJECT_FOCUS,
  WINEVENT_OUTOFCONTEXT)`. На событие: pid → `QueryFullProcessImageNameW` (UWP: дочерний
  CoreWindow), elevated (`TokenElevation`), полный экран (`SHQueryUserNotificationState` + размер
  окна = монитор), IME (`HKL` старшие биты 0xE…), пароль (`ES_PASSWORD` у `hwndFocus`, иначе UIA
  `CurrentIsPassword` у `GetFocusedElement` с таймаутом 100 мс). Результат — `ArcSwap<Context>`.
  Любое событие фокуса сбрасывает слово и окно отмены.
- **Rationale**: тяжёлые вызовы раз на смену фокуса, не на клавишу.

## R8. Ручная конвертация выделения

- **Decision**: Pause: если после последнего сброса есть «последнее слово» — перепечатать его;
  иначе запомнить `GetClipboardSequenceNumber`, сохранить буфер обмена (`clipboard-win`), отправить
  Ctrl+C, ждать смены номера до 150 мс; есть текст — конвертировать посимвольно (таблицы R2),
  вставить Ctrl+V, восстановить буфер через 300 мс. Нет — ничего не делать.
- **Rationale**: выделение мышью/Shift+стрелками сбрасывает буфер, значит «нет последнего слова»
  надёжно означает «работаем с выделением».

## R9. Оболочка и конфиг

- **Decision**: Tauri 2 (minor как у остальных приложений, CLI 2.11.x), трей `tray-icon`,
  `tauri-plugin-single-instance`, `tauri-plugin-autostart` (HKCU Run), окно настроек создаётся по
  требованию и уничтожается при закрытии. Конфиг — `%APPDATA%\Ghbdtn\config.toml` (serde + toml),
  горячая замена в ядре через `ArcSwap<Config>`. Frontend — Vite + React 19 + TS, как в Booked.
  Релиз — `stillmvd/tauri-ship`.
- **Звук**: `PlaySoundW` из ресурса — без аудио-крейтов.

## R10. Корпус качества

- **Decision**: тест `cargo test --release -p ghbdtn-core --test corpus`: топ-10K слов каждого языка
  из частотного списка → (а) набраны в своей раскладке: доля изменённых ≤ 0,1 % (SC-001);
  (б) длина ≥ 3, набраны в чужой: доля исправленных ≥ 95 % (SC-002); (в) опечатки — синтетические
  правки dist 1 для слов ≥ 5 букв: верно ≥ 70 %, неверно ≤ 1 % (SC-003). Плюс «трудный набор»
  (код, команды, ники, аббревиатуры) — ноль изменений.
