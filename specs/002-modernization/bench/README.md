# Стенд 002 — результаты по фазам

Запуск: `cargo build --release -p ghbdtn-core --example rivals`, затем
`src-tauri/target/release/examples/rivals.exe <ghbdtn|installed|none|имя> <out.jsonl> [gap]`. Печатает в Блокнот.

- `ghbdtn` — движок внутри стенда (`ACCEPT_INJECTED`), в сводке есть разбивка по шагам `stages`.
- `installed` — установленная сборка, запущенная с `GHBDTN_ACCEPT_TEST_INPUT=1`; стенд шлёт ввод с `TEST_MARK`.
  Шагов движка в сводке нет (другой процесс).
- Punto/Caramba на время прогона выключать.

Шаги (`hook::STAGES`, ср/макс): `queue` — от нажатия разделителя в хуке до обработки в движке; `evaluate` — статус
окна и раскладки; `decide` — решение; `send` — `SendInput` исправления; `switch` — смена раскладки с ожиданием.
«Движок» = от разделителя до конца `SendInput` (FR-002).

## Phase 4 — 2026-10-16, `phase4.jsonl`

Ранняя правка (`early.rs`, `Rule::Early`): начало слова 3–6 букв невозможно в текущем языке (таблица начал: частотный
список, словарь hunspell с приставками PFX, словоформы OpenCorpora, IT/тех-слова, слова пользователя и замены), доля
слов с этим началом в целевом языке ≥ 2e-5 и ≥ 10× суммы долей вариантов текущего начала с одной опечаткой (соседняя
клавиша, перестановка, пропущенная буква). Не в режиме кода; `features.early` (вкл.); список «не трогать» блокирует.
Если к моменту решения в очереди уже есть клавиши, прошедшие мимо задержки, — правка откладывается до пробела.
